# Smart Vending Machine

This project implements a complete smart vending machine flow using:
- ESP32 touchscreen for user interaction and QR payment display
- Arduino stepper controller for motor dispensing
- Python FastAPI backend for order creation, QR generation, and payment simulation

## Project structure

- `src/main.cpp` — ESP32 touchscreen firmware
- `arduino_stepper/stepper_controller.ino` — Arduino stepper motor controller sketch
- `vending_backend/server.py` — backend server for order/payment flow
- `vending_backend/requirements.txt` — backend Python dependencies
- `platformio.ini` — ESP32 build configuration

## Features

- Touchscreen item selection on ESP32
- Order creation via backend API
- Payment QR generated by backend and shown on ESP32
- Mobile browser payment flow via `/checkout?order_id=...`
- WebSocket backend → ESP32 command to dispense after payment
- Arduino stepper controller receives `M1`, `M2`, `M3` commands and returns dispense status

## Setup

### 1. Backend

1. Open a terminal in `vending_backend/`
2. Install dependencies:
   ```bash
   python3 -m pip install -r requirements.txt
   ```
3. Run the backend server:
   ```bash
   python3 server.py
   ```

### 2. Configure ESP32 firmware

1. Open `src/main.cpp`
2. Set these values to your network and backend:
   - `ssid` — your Wi-Fi SSID
   - `password` — your Wi-Fi password
   - `backendHost` — the backend server IP address
   - `backendPort` — usually `8000`
3. Build and flash using PlatformIO.

### 3. Arduino stepper controller

1. Flash `arduino_stepper/stepper_controller.ino` to the Arduino.
2. Connect the Arduino and ESP32 via serial:
   - ESP32 `TX2` (GPIO 17) → Arduino `RX` pin
   - ESP32 `RX2` (GPIO 16) → Arduino `TX` pin
3. Ensure the Arduino stepper motor pins match your wiring.

## Runtime flow

1. User taps a product on the ESP32 touchscreen.
2. ESP32 creates an order with the backend.
3. Backend returns a payment URL and QR data.
4. ESP32 displays the QR code.
5. User scans QR and pays in the phone browser.
6. Backend marks order paid and sends dispense command over WebSocket.
7. ESP32 forwards the command to Arduino over serial.
8. Arduino runs the stepper motor and reports `DONE` or `FAILED`.

## Notes

- The backend currently simulates payment. Replace the `/pay` logic with a real payment gateway if needed.
- The QR code is generated server-side and rendered on the ESP32 screen as a pixel matrix.
- Touch calibration may require adjustments for your specific screen.

## Troubleshooting

- If the ESP32 cannot reach the backend, confirm `backendHost` is reachable from the same Wi-Fi network.
- If the motor does not spin, verify the Arduino serial wiring and stepper driver wiring.
- Use serial output on both ESP32 and Arduino to inspect messages.

- Run backend server:

